🚨 Важные предупреждения

- Все утилиты запускаются только от имени администратора.  
- Перед началом рекомендуется создать точку восстановления.  
- Комьюнити‑утилиты могут трогать WMI, службы и политики — использовать осторожно.  
- Набор предназначен для лечения, а не для постоянной защиты.  
- Скачивайте программы только с официальных источников.

🧨 Пошаговая инструкция по очистке ПК

Этап 1 — Снятие блокировок и зачистка майнеров

1. Запустить AV Block Remover (AVbr) → снять вредоносные политики → ПК перезагрузится.  
2. После перезагрузки запустить Miner Search → удалить скрытые майнеры и WMI‑подписки.  
3. Запустить DoesNotBelong → удалить вредоносные службы и задачи.

---

Этап 2 — Глубокая антивирусная проверка

4. Запустить Emsisoft Emergency Kit → Full Scan → удалить угрозы.  
5. Запустить Dr.Web CureIt! → вылечить повреждённые системные файлы.

---

Этап 3 — Восстановление системы

6. Открыть AVZ 6.12 → Файл → Мастер поиска и устранения проблем → Системные проблемы → Исправить.

❓ FAQ

Как понять, что у меня майнер?  
— Высокая загрузка CPU/GPU без причин, закрывающиеся окна антивирусов, блокировка сайтов защитных компаний.
Можно ли использовать только один сканер?  
— Можно, но эффективность будет ниже. Набор рассчитан на тяжёлые случаи.
Что делать, если Windows не загружается после чистки?  
— Использовать точку восстановления или WinRE → Восстановление системы.
